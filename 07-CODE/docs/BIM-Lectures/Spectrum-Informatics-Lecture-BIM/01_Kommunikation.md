Einheiten, die Informationen miteinander austauschen, benötigen:

- ein gemeinsames Übertragungsmedium (Luft, Kupferkabel)
- Kommunikationskanäle (Stimme, Frequenzen)
- Transportmechanismus (Sprache, Protokolle)

Kommunikationsnetzwerke können weltumspannend sein und aus tausenden von adressierbaren Geräten bestehen, oder sie verbinden zwei Computer zu Hause.
