## IPv6
- Bisher werden in IPv4 32-Bit Internet-Adressen benutzt
- Nachteile:
	- Begrenzter Adressraum
	- Zu klein für heutige und zukünftige Anforderungen
	- Zu unflexibel gegenüber Weiterentwicklungen
- Als Reaktion darauf wurde eine neuen Version des Internetprotokolls IPv6 entwickelt
- Die IP-Adresse hat in IPv6 eine Länge von 128 Bit
- Es gibt keine Adressklassen wie in IPv4
### Public Topology
- Öffentliche Topologie von Internet-Providern
- FP: Format Prefix, binär 001
- TLA ID: Top-Level Aggregation Identifiers, oberste Stufe der Routing-Hierarchie (Provider)
- RES: Reserviert für spätere Verwendung
- NLA ID: Next-Level Aggregation Identifiers, der Besitzer einer TLA ID hat 24 Bit für eigenen Routing Hierarchie zur Verfügung
### Site Topology
- Interne Topologie, z.B. Campus-internes Netzwerk, Firmennetz
- SLA ID: Site-Level Aggregation Identifiers für die interne Routing-Hierarchie
### Interface Identifier
- Schnittstellen-Identifikator, der den Host IDs der IPv4 entspricht
- 64 Bit stehen zur Verfügung
## Adressierung IPv6
- Eine Voraussetzung für den geordneten Übergang zur neuen IP-Version sind Rechner und Router mit einer Netzwerkschicht, die beide IP-Versionen unterstützt
- Auch IPv6 Datagramme müssen mit einem IPv4 Header versehen und über das vorhandene IPv4-Netzwerk übertragen werden
- IPv6 Adressen bestehen aus 128 Bit, die wie folgt dargestellt werden: x:x:x:x:x:x:x:x, wobei jedes x 16 Bit repräsentiert
- Zwei IPv6 Adresstypen sind definiert:
	- Eine IPv4-kompatible IPv6 Adresse (auch eingebettete Adresse) hat das allgemeine Format: 0:0:0.0:0:0:y:y, wobei y:y die 32 Bit lange Internet-Adresse der Version 4 darstellt
	- So ergibt sich z.B. für den Rechner 128.1.0.1 die IPv4 kompatible IPv6-Adresse 0:0:0:0:0:0:8001:0001 oder kurz ::8001:0001 oder dezimal ::128.1.0.1
## Quality of Service
- Die Dienstgüte ist eine der wichtigsten Entwicklungen in IPv6
- Sie kann von der Sendestation angefordert werden
- Durch Angabe einer Priorität lässt sich die Dringlichkeit eines Datenpaketes bestimmen
- Die QoS wird von Routern auch zur Steuerung des Datenflusses verwendet (anders als bei IPv4)
- Eine sogenannte Flussmarke identifiziert alle Pakete eines Datenflusses und bewirkt Gleich- bzw. Sonderbehandlung (Flow)
## IPv6 Datagramm-Header
- Die Weiterentwicklung des neuen Internetprotokolls Version 6 und die damit verbundenen Anforderungen spiegeln sich auch im IPv6 Diagramm-Header wieder
- Version: Gibt die Versionsnummer des verwendeten IP-Standards an
- Priority: Der Vorrang für die Weiterleitung wird spezifiziert. Der erste Bereich (0 bis 7) bezieht sich auf den Datenverkehr, der seine Datenrate des Lastbedingungen anpasst, der zweite Bereich (8 bis 15) auf den, der dies nicht tut.
- Flow Label: Kennzeichnung der zu einem Datenfluss gehörenden IP-Datagramme mit speziellen Anforderungen z.B. max. Verzögerung
- Payload Length: Anzahl der Bytes, die auf den Header folgen und zum IPv6 Datagramm gehören
- Next Header: Definiert Erweiterungs-Header mit Zusatzinformationen. Das Feld definiert, welchen Typ der unmittelbar folgende Header besitzt. Es wird auch spezifiziert, welches Transportschichtprotokoll das jeweilige IP-Datagramm benutzt. Der Wert 59 zeigt an, dass kein weiterer Header folgt.
- Hop Limit: Jeder Netzwerkknoten, der ein IP-Datagramm weitergibt, verringert den Wert des Feldes Hop Limit um eins. Erhält das Feld den Wert 0, wird das Diagramm verworfen
- Source Address, Destination Address: Beim IPv6 sind jeweils 128 Bit für die Quell- und die Zieladresse reserviert
