# Das Web of Data
- besteht aus verknüpften Daten-Endpunkten im Web (Linked Data, SPARQL)
- basiert auf RDF als Datenaustauschformat
- Bibliotheken nutzen Endpunkte, bieten Endpunkte an und stellen Verknüpfungen her
#### Das Netz der Hypertext-Dokumente (1992): Web 1.0
- Viele verschiedene Webseiten mit textuellem Inhalt
#### Das Web der Nutzerbeteiligung (2003): Web 2.0
- Viele verschiedene Webseiten mit textuellem Inhalt
- + Wenige sehr große Webseiten spezialisiert auf spezifische Inhaltstypen
#### Das Web der Daten: Web 3.0
- Viele verschiedene Webseiten mit textuellem Inhalt
- Wenige sehr große Webseiten spezialisiert auf spezifische Inhaltstypen
- + Viele Webseiten enthalten und verweisen auf semantisch strukturierte Inhalte
## Geschichtswissenschaftliche Recherche im Web of Data
Suche nach naturwissenschaftlichen Professoren der Universität Leipzig, welche gemeinsam mit Autoren der Bundesrepublik Deutschland in den Jahren 1980 bis 1989 publizierten.
# Wissenschaftliche Recherche
## Beispiel: Wissenschaftliche Recherche
- Fragestellung in der prosopographischen Forschung:
	- Publikationen aller naturwissenschaftlichen Professoren der Universität Leipzig, welche gemeinsam mit Autoren der Bundesrepublik Deutschland in den Jahren 1980 bis 1989 publizierten.
- Ergebnis: Liste von Publikationen
- Informationsquellen:
	- Professorenkataloge der Universität Leipzig
	- Abfragen von Metadaten-Datenbanken und Bibliothekskatalogen
	- Einbeziehung genereller Informationen (z.B. Wikipedia, OpenStreetMap)
